# 逐段改写手册

## 判断问题出在哪里

借鉴 humanizer-zh-academic 的句式诊断，先看段落怎样展开，再决定是否换词。借鉴 academic-humanizer-zh 的两层审读，同时看表面重复和论证依据。词汇少、句子短的段落也可能缺少依据；术语反复出现有时恰好是准确指称。每次判断都应指向原文的一处具体表达。

| 原文出现的现象 | 编辑判断与做法 |
|---|---|
| 连续用“基于……理论”起笔 | 找出本段真正讨论的设计选择。若重点是界面，把操作或对象放在前面，理论与引用仍紧贴它所解释的选择。综述以理论为主题时可保留原顺序。 |
| 一段列出三项同样工整的成效 | 看三项是并列、先后还是因果。任务完成、领取水滴、布置鱼缸有操作次序，按操作发生顺序写。真正并列的界面名称仍逐项列全。 |
| 频繁出现“通过……实现……有效提升” | 分清界面显示了什么、用户能做什么、效果是否测过。图稿能支持描述入口的位置，效果判断则要回到实际评价材料。 |
| 每段末尾都有“由此可见”“具有重要意义” | 遮住末句读一遍。若没有损失信息，可删去重复评价；若末句含唯一限制条件或引文，保留该信息。 |
| 名词密集，出现“页面信息展示功能的设计” | 保留专名，压缩其外围表达。“习惯库”“我的任务”等界面原词逐字保留。相邻两个名词指向不同时，宁可重复名称也要避免“其”“该”指代不清。 |
| 连续短句反复出现同一个主语 | 同一次操作可以合写，到了条件分支或结果发生变化处再断句。依语义使用“把、了、会、能”；不设助词或标点配额。 |
| “研究表明”“普遍认为”没有清楚指向 | 查本段所引文献和原稿已有说明。可确认时写明谁研究了什么，来源不明则标出待核实，勿自行补作者或结论。 |

## 不同章节怎样落笔

- 综述与案例分析要分清来源观点、案例现象和作者取舍。引文跟随原命题移动，保留“提示”“相关”“可能”等判断强度。
- 需求分析要分清用户画像、访谈记录和统计结果。画像里的角色年龄或偏好可以描述人物设定；把它写成受访者比例则需要样本依据。
- 设计说明可以按“从哪里进入、看到什么、动作后发生什么”挑与本段相关的部分写。按钮名、状态词与当前图稿核对。两张图仅展示两个状态时，慎写动画时长、后端处理或真实测试效果。
- 结论区分已经交付的设计、确实观察到的现象和计划中的验证。原稿写“后续开展访谈”，改后仍用将来语气。

## 对照练习

原句：“原型检查从创建阅读任务开始，依次经过填写、保存、计时和返回，任务结束后继续查看完成状态与资源领取提示。”

可改：“检查原型时，先新建一项阅读任务，填好后保存，再开始计时。任务结束并返回列表后，接着核对完成状态和资源领取提示。”改动把长串动作分成录入和核对两个阶段。只有原稿已明确返回列表时才写“返回列表”；若去向未知，写“返回后”。若要求标点序列完全一致，应在原句的分句位置内调整。

原句：“产量提升了40%。”保留比较对象和增长方向；原稿有基准时可写“产量比上期提高了40%”。“40%的产量得到了提升”把增长幅度写成一部分产量所占的比例，不能采用。缺少基准时沿用原句。

## 复读

关掉报告，只读修改句和前后两句。逐项回答：读者能否认出动作主体？顺序与图稿是否一致？术语、数值及单位是否完整？删掉的套话中是否藏有条件或转折？新增细节能否在原稿找到？把无法回答的地方退回原句重新处理。项目自带的文本评分最多用于定位重复模式，商业平台复测结果单独记录。

## 标记句的第二遍审读

先按本节任务写出改稿，再以论文读者的身份读一遍。对照原文，找出新句里第一次出现的评价、因果、范围或承诺。每一项都应能指回原句、图稿或所引文献。对已经具体、准确的句子，可记录“已审读，保留”，无需为制造差异硬换词。

| 遇到的句子 | 该查什么 | 局部处理 |
|---|---|---|
| “页面设置暂停按钮，彰显了对青年群体深层心理需求的关注。” | 截图能证实按钮存在。心理需求判断要有对应材料。 | 若本段介绍操作，可写“用户可在计时页暂停计时”。若本段讨论需求，回查需求材料并保留有依据的解释。 |
| “从饮水打卡到生态文明建设，设计实现了多层次价值。” | 两端之间是否有本文研究过的过程？ | 若原稿只展示任务完成和水滴奖励，可写“用户确认饮水任务已完成后，可以领取水滴”。“确认完成”若为按钮名，要逐字保留。 |
| “相关研究充分证明这种界面更受青年欢迎[8]。” | 核对[8]的研究对象、指标与比较对象。引文格式正确也可能支持不了“更受欢迎”。 | 能查到依据时，写清文献实际观察到的结果。材料不足时保留待核实项，不补作者、页码或 DOI，不把引文移到另一项推断后。 |
| “下面将为您详细介绍三个页面，希望能为您提供参考。” | 句子是否只有面向提问者的交代？三个页面的名称是否已经在下文出现？ | 若下文直接进入页面说明，可删去标记内的客套语。若该句承担首次引图功能，保留页名和图号。 |

反向检查一个容易误改的例子：“问卷采用五点量表，分别测量易用性、满意度和使用意愿。”三项是测量维度，拆掉其中一项会改变方法。即使报告标记了这句，也应保留量表、维度和数量。英文编辑资料里的排比、标点和常用词观察同样要结合中文语境使用；不能据此批量替换破折号、技术名词或固定按钮文案。
