# 论文查重修改 · thesis-report-revision-zh

一个用于中文论文局部修订的 Codex 技能。把 PaperPass、维普等平台的检测报告和对应版本的 Word 原稿一起交给 Codex，它会按本次报告的图例定位标记句，在原稿对应位置改写，并核对专有名词、数字、引文和排版。

适合反复修订同一篇论文的场景。例如，报告只标记了某段的第二句，而第一句含图号、第二句末尾有上标文献编号，修改范围就限定在第二句，并检查上标是否仍紧跟它支持的观点。

## 快速开始

1. 下载或克隆本仓库，保留根目录的 `SKILL.md` 和 `references/` 文件夹。
2. 在能访问这些文件的 Codex 会话中，指定 `SKILL.md` 的路径，并提供检测报告、对应的论文原稿和输出文件名。
3. 用下面的提示词开始。若只想修改特定等级（例如仅红色），可在提示词中直接写明。

> 使用当前仓库的 SKILL.md。根据我提供的《初稿-AIGC检测报告.docx》，修改《初稿.docx》中被标记的文字。保留专有名词、数据、引用上标、图号、原有格式和全半角习惯。在原文件夹另存为《初稿-修订版.docx》。完成后告诉我实际改了多少处，单独列出无法匹配的标记。

要在多个项目中复用，可把整个目录安装到个人技能目录。以下是 Windows PowerShell 示例（使用默认 Codex 主目录）：

```powershell
$skillsDir = Join-Path $env:USERPROFILE '.codex/skills'
New-Item -ItemType Directory -Force $skillsDir | Out-Null
git clone https://github.com/Alife1131/thesis-report-revision-zh.git (Join-Path $skillsDir 'thesis-report-revision-zh')
```

在新会话中可用 `$thesis-report-revision-zh` 点名调用，并附上报告和原稿。文档修改和预览由当前环境中可用的 Word 文档工具完成。

## 修订时怎样判断

- **定位原句。** 按当前报告的颜色或等级说明读取标记。遇到相同原句时，用章节和前后文定位。报告与原稿版本有差异时，单列无法确认的位置。
- **按证据改写。** 术语密集的句子保留术语、压缩外围套话；需要展开时，从原稿或对应图中提取已有细节。描述设计方案、已实现功能和测试结果时，分别保持原文的证据强度。
- **核对 Word。** 对照原稿检查非目标段落、字符样式、上标、图号及全半角。涉及分页时，交付说明应区分文件结构检查和实际页面预览。
- **交付修订版。** 分别说明标记处数、匹配情况和实际改动数。同一段有三处标记时，按“三处、一段”记录。AIGC 检测与文字重复检测采用各自报告的口径，修订后的数值以对应版本的实际复测为准。

## 用自然语言调用

在支持自动发现技能的助手中，可直接说“这份维普报告更新了，帮我改一下标红的地方”，也可以同时附上报告和原稿，说“只处理报告里圈出的句子，另存一份”。助手可结合附件、上下文和技能描述判断是否适用。只询问检测结果含义时，先解释报告；用户要求修改时再写回原稿。

其他助手若支持项目规则，但不能自动发现这个技能，可在其项目规则中加入下面一条，并将路径换成技能入口的实际位置：

> 用户要求依据查重或 AIGC 检测报告修订论文时，先读取并遵循 `thesis-report-revision-zh/SKILL.md`。结合附件和上下文理解“只改标红”“报告更新了，继续改”等表达。用户只要求解读时，仅解读报告。

自动调用取决于宿主软件是否加载技能描述或项目规则。只能接收聊天文本的工具可在对话开头附上技能入口和两份参考手册。
